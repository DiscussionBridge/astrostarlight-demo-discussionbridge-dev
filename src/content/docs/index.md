# DiscussionBridge for Astro: Starlight Demo

This is the live stock Starlight demo for DiscussionBridge for Astro. It uses
the exact packaged adapter artifact pinned by this site.

The discussion section is added by a Starlight `MarkdownContent` override, so this page can remain plain Markdown while comments stay attached to the page body.

This page uses the plugin-free Discourse Core path. Its canonical URL owns the
discussion on The Bridge without a receiver credential or hard-coded topic.
