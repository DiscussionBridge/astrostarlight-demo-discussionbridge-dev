## Release lane demo

This release note lives in `src/content/releases`, separate from the Starlight docs collection.

This release entry uses the plugin-free Discourse Core path. Its canonical URL
owns the discussion on The Bridge without a copied topic binding.

### Highlights

- Release notes can use a Starlog-style content collection.
- The same Discussion component can appear on release detail pages.
- Publish settings can vary by lane without splitting the Astro site.
